# 钢板视觉缺陷检测项目

基于 `FastAPI + SQLite + YOLO26` 的前后端一体化项目，用于钢板表面缺陷检测。

当前统一输出两类结果：

- `defect`：有缺陷
- `normal`：无缺陷

## 已实现能力

- 后端接入 USB 摄像头或 RTSP 视频流
- 前端实时显示视频画面
- 前端实时显示正常 / 异常状态
- 后端叠加异常框与置信度
- 异常帧自动存储并可查询历史
- 识别链路精简为当前实际使用的 YOLO26 模型

## 启动说明

直接双击桌面上的 `run_steel_detection.bat`。

脚本会：

- 创建虚拟环境（若不存在）
- 安装 Web 端运行依赖
- 启动后端服务
- 等待约 4 秒后自动打开浏览器

注意：

- 如果没有放置 `backend/models/yolo26-steel.pt`，页面也能打开，但模型状态会显示未就绪
- 如果要做真实检测，需要准备权重文件，并保证视频源可用
- 本机只有 Python 3.14，因此脚本已改为安装兼容 3.14 的 Web 依赖版本
- 仓库仅保留当前在用的服务代码和训练脚本，历史实验产物与未接入算法已清理
